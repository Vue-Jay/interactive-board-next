# Lektrus: кроссплатформенная версия

Одна кодовая база React/Vite обслуживает ПК, планшеты и телефоны. Браузерная версия работает на Windows, macOS, Linux, Android и iOS. PWA устанавливается в отдельное окно/на домашний экран в браузерах с поддержкой установки.

## Установка

1. Опубликуйте содержимое `dist/` на HTTPS-домене. На произвольном LAN HTTP-адресе установка PWA обычно недоступна. `localhost` является исключением для разработки.
2. Войдите в Lektrus и откройте **Настройки → Приложение для вашего устройства**.
3. В Chromium (Chrome/Edge на ПК или Android) нажмите **Установить**, когда кнопка доступна.
4. iPhone/iPad: откройте сайт в Safari, затем **Поделиться → На экран Домой**.
5. macOS Safari: **Файл → Добавить в Dock** (доступно в поддерживаемых версиях macOS/Safari). Другие браузеры могут предлагать ярлык, а не PWA.
6. Firefox и другие браузеры без install prompt: используйте инструкции в настройках или открывайте сайт как обычную веб-версию.

Поддержка установленной PWA **не означает** наличия APK, IPA, EXE или DMG. Для распространения отдельных нативных пакетов понадобятся обёртки, подписи и проверки целевых ОС.

## Offline и обновления

Service worker сохраняет только оболочку приложения, публичный логотип, манифест и хешированные сборочные ресурсы `/assets/`. При отсутствии сети ранее загруженный интерфейс может открыться, но авторизация, получение новых досок, серверное сохранение и совместная работа требуют интернета. **Содержимое досок, ключи приглашений, Supabase API, загружаемые файлы и личные данные в Cache Storage не складываются.**

HTML-навигация использует стратегию network-first. Запросы маршрутов `/join/:token` не кешируются. Для `/assets/` используется cache-first, потому что у Vite уникальные хешированные имена файлов. При установке новой версии пользователь увидит предложение обновить приложение на открытой доске, а не принудительную перезагрузку посреди занятия.

## Разработка и приёмка

```bash
npm ci
node scripts/test-lektrus-platform.mjs
npm run test:ui
npm run build
npm run dev
```

`vite.config.ts` слушает `0.0.0.0:5173`, чтобы сайт был доступен по адресу LAN-интерфейса, например `http://192.168.0.10:5173`. Это только локальное тестирование; оно не делает HTTP безопасным и не обеспечивает установку на другие устройства.

Проверьте на Windows Chrome/Edge, macOS Safari/Chrome, Linux Chrome/Firefox, Android Chrome и iPhone/iPad Safari:

- нормальный вход в аккаунт, выход и повторный вход;
- установка и запуск по иконке, портретная/горизонтальная ориентация;
- рисование мышью, пальцем и стилусом, выделение, прокрутка и изменение масштаба;
- открытие доски по ссылке, роли преподавателя и ученика, Realtime с двух устройств;
- загрузка изображений/PDF, доступ к редакторам, клавиатуре и полям ввода;
- потеря сети и восстановление: статус соединения понятен, после возвращения сети не теряются сохранённые данные;
- публикация новой сборки: предложено обновление без автоматического прерывания занятия.

Не включайте старые Tuqo/Vercel workflow. Текущий код не делает деплой и не меняет параметры Supabase.
