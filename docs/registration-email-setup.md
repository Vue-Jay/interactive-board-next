# Настройка письма с кодом Lektrus

В приложении уже есть собственная страница регистрации и поле для одноразового кода. Чтобы письмо также выглядело как письмо Lektrus, выполните настройку в проекте Supabase:

1. В разделе **Authentication → Email Templates → Confirm signup** замените HTML шаблоном `supabase/email-templates/confirm-signup.html`.
2. Убедитесь, что в шаблоне остался маркер `{{ .Token }}`: он подставляет одноразовый код, который вводится в интерфейсе Lektrus.
3. В разделе **Project Settings → Authentication → SMTP Settings** подключите SMTP вашей почты или выбранного почтового сервиса. Не добавляйте SMTP пароль в репозиторий или клиентское приложение.
4. Проверьте регистрацию на адресе вне списка владельцев проекта: стандартная отправка Supabase ограничена тестовым использованием, а для реальных адресов нужен собственный SMTP.

Проверка адреса, срока действия кода, защита от повторной регистрации и выдача сессии остаются на сервере аутентификации. Веб-страница подтверждения Supabase пользователю не показывается: код вводится в Lektrus.
