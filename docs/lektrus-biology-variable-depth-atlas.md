# Lektrus · Атлас организмов без универсальной пятиступенчатой анатомии

## Почему отдельная модель
У позвоночного удобно переходить «организм → система органов → орган → ткань → клетка». Для губок, гидры, мхов и многих водорослей этот путь создаёт научные ошибки. В новом локальном редакторе `src/lektrusBioAlternativeAtlas.ts` структура выбирается через **граф с реальными типами узлов**: организм, поколение, анатомическая структура, клеточный слой/ткань, клетка, органоид, размножение. Каждая ветвь может закончиться на собственной глубине.

Инструмент реализован как **режим изучения атласа**, не как новый тип сохраняемого задания. Существующие сохранённые доски, пятиуровневые схемы и задания сохраняют прежний формат. Классовый каталог соединяет модель с пятью строго совпадающими научными именами; неподготовленные виды остаются без придуманной схемы.

## Виды и подтверждаемые объекты
| Вид | Главное в атласе | Научное ограничение |
| --- | --- | --- |
| Бадяга озёрная, *Spongilla lacustris* | Поры, водоносная система, жгутиковая камера, хоаноцит, амёбоцит, геммула | **Нет истинных тканей и органов** |
| Гидра обыкновенная, *Hydra vulgaris* | Щупальца, эпидермис, книдоцит/нематоциста, кишечная полость, гастродерма, почка | Есть клеточные слои, но нет сложных систем органов |
| Кукушкин лён, *Polytrichum commune* | Гаметофит, ризоиды, листовидные структуры/ламеллы, спорофит, ножка и коробочка, протонема | Ризоиды ≠ настоящие корни; гаметофит **n**, спорофит **2n** |
| Хламидомонада, *Chlamydomonas reinhardtii* | Жгутики, базальные тельца, хлоропласт/пиреноид, глазок, ядро, вакуоли | **Одноклеточная**: нет тканей и органов |
| Спирогира, *Spirogyra communis* | Нить, клетка, спиральный хлоропласт, пиреноид, ядро, конъюгация, зигоспора | Нет настоящих органов; зигоспора **2n** |

### Жизненные циклы
Для *Polytrichum commune* отдельно перечислены фазы:
спора (n) → протонема (n) → гаметофит (n) → оплодотворение/зигота (2n) → спорофит (2n) → мейоз/споры (n). Здесь гаметофит и спорофит **разные поколения**.

Для спирогиры показаны гаплоидная нить, половая конъюгация, диплоидная зигоспора и возвращение к гаплоидному состоянию через мейоз при прорастании.

## Проверяемые научные источники
- [OpenStax Biology 2e: губки](https://openstax.org/books/biology-2e/pages/28-1-phylum-porifera) — хоаноциты, водоносная система, отсутствие истинных тканей и образование геммул.
- [OpenStax Biology 2e: стрекающие](https://openstax.org/books/biology-2e/pages/28-2-phylum-cnidaria) — книдоциты, нематоцисты, эпидермис и гастродерма.
- [OpenStax Biology 2e: мохообразные](https://openstax.org/books/biology-2e/pages/25-3-bryophytes) — гаметофит/спорофит, ризоиды, образование спор, мейоз.
- [PMC: Chlamydomonas eyespot](https://pmc.ncbi.nlm.nih.gov/articles/PMC3811559/) — строение фоточувствительного глазка и передние жгутики.
- [NIOS Biology, chapter on Spirogyra](https://allenwebsite-general.s3.ap-south-1.amazonaws.com/nios/download/sr-secondary/Biology_314_Book2.pdf) — нитчатая форма, хлоропласты и конъюгация.

Ссылки поддерживают **обобщённые признаки**, а не подтверждают микроскопические изображения каждого отдельного экземпляра. Авторские SVG-схемы иллюстративны и намеренно отмечены «не в масштабе». Никаких точных размеров клеток без измерений не заявляется.

## Проверка
`npm run test:biology-atlas` проверяет новые графы, уникальность узлов, отсутствие вымышленных тканей у губки, плоидность мха, наличие двух специальных жизненных циклов, привязку к верному виду в каталоге, координаты точек и обратную совместимость. В CI дополнительно выполняется сборка TypeScript/Vite.

Следующий этап: полноценные морфологические атласы остальных главных классов, фотографии с масштабными линейками и отдельный режим создания заданий по анатомии без пятиступенчатого ограничения.
