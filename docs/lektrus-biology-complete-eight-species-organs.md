# Lektrus · Полная рисовка органов и тканей восьми видов

## Итерация

Создано **32 новых интерактивных SVG-рисунка**: 16 органов и 16 тканевых
срезов. Совместно с предыдущими пластинами атлас содержит отдельные
изображения всех **24 органов и 24 тканей** восьми представленных видов
(по три анатомические ветви у каждого).

| Вид | Новая ветвь 1 | Новая ветвь 2 |
|---|---|---|
| Воробей | Кожа → эпидермис → кератиноцит | Глаз → сетчатка → колбочка |
| Окунь | Боковая линия → сенсорный эпителий невромаста → волосковая клетка | Сердце → миокард → кардиомиоцит |
| Лягушка | Лёгкие → дыхательный эпителий → эпителиальная клетка | Глаз → сетчатка → палочка |
| Пчела | Трахея → трахейный эпителий → трахейная клетка | Лётная мышца груди → поперечнополосатая ткань → мышечное волокно |
| Улитка | Глаз верхнего щупальца → фоторецепторный эпителий → фоторецептор | Мантия → эпителий → покровная клетка |
| Сосна | Молодой корень → ризодерма → клетка с корневым волоском | Микроспорангий → спорогенная ткань → микроспороцит |
| Орляк | Вайя → мезофилл → клетка мезофилла | Придаточный корень → кора → клетка паренхимы |
| Пшеница | Лист → мезофилл → фотосинтезирующая клетка | Молодой корень → ризодерма → клетка с корневым волоском |

### Отображение

Рисунки индивидуальны для конкретного вида и конкретной ткани. При выборе
узла отображается собственная SVG-схема с выносками и кнопкой перехода
к реальному дочернему узлу. Ссылка на подтверждающий научный материал
и описание показываются существующей карточкой биологического микроскопа.

Чтобы не ломать старые задания, идентификаторы узлов `BioNode`,
сохранённые пути и прежние восемь пар орган/ткань не изменены.
Новый диспетчер разрешает схемы по виду, уровню и точному названию
узла с дополнительной проверкой родового префикса пути.

### Особенности научной корректности

- Купула невромаста передаёт движение воды волосковым клеткам. В схеме
  показаны и сенсорные, и поддерживающие клетки.
- Сердце окуня не изображено как четырёхкамерное сердце млекопитающего.
- Лёгкое взрослой лягушки имеет внутренние складки, не человеческое
  альвеолярное дерево.
- Воздух в трахейной системе пчелы движется по хитиновым трубкам; гемолимфа
  не выполняет основную роль в транспорте кислорода.
- Фоторецепторный эпителий улитки изображён отдельно от палочек и
  колбочек позвоночных, без ложной подмены сетчатки моллюска.
- Корневые волоски сосны и пшеницы суть выросты отдельных живых клеток
  ризодермы.
- Диплоидные материнские клетки внутри микроспорангия образуют
  гаплоидные микроспоры после мейоза, а не одновременно.

Изображения являются **авторскими учебными схемами, не микрофотографиями**.
Их пропорции и цвета условны; оптическая масштабная линейка не
имитируется.

### Код и регрессия

- `src/lektrusBioAdditionalSpecimenPlates.ts`: 16 пар метаданных с
  точными биологическими путями, источниками и координатами.
- `src/LektrusBioAdditionalSpecimenArt.tsx`: 32 вида учебных
  оригинальных SVG-пластин.
- `src/lektrusBioSpecimenPlates.ts`, `src/LektrusBioOrganDetail.tsx`:
  обратносуместимый показ новых изображений рядом со старыми.
- `scripts/test-lektrus-bio-complete-organ-tissue.mjs`:
  проверка всех 48 пластин, 16 новых пар, принадлежности
  к виду, реальных дочерних узлов, источников, координат и
  сохранения прежней навигации.

Дальше остаются: больше видов среди 75 групп таксономического браузера,
настоящие лицензированные микрофотографии с измеренными линейками,
дополнительные ткани и сезонные/возрастные стадии для выбранных видов.
