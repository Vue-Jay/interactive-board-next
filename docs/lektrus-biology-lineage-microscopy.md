# Подробный микроскопический атлас восьми биологических линий

После обновления внешнего облика 20 организмов создано ещё 48 отдельных учебных SVG-сцен: 24 анатомические ветви × 2 уровня (ткань и клетка). Каждая ветвь сохраняет уже существующие идентификаторы узлов и упражнений.

| Организм | Изучаемые ткани и клетки |
|---|---|
| Дождевой червь | Эпидермис с железистыми клетками; ресничная нефростома; кишечный эпителий с тифлозолем |
| Морская звезда | Покров подия; пилорический железистый эпителий; дерма с оссикулами |
| Речной рак | Жаберные нити; канальцы антеннальной железы; мышечные волокна брюшка |
| Хвощ | Хлоренхима стебля; устьица; спороциты |
| Ящерица | Базальные кератиноциты; лёгочная фовеола; фоторецепторы сетчатки |
| Паук | Ламеллы книжного лёгкого; паутинные железы; рабдомерные фоторецепторы |
| Плаун | Мезофилл микрофилла; спорогенная ткань; ризодерма |
| Магнолия | Мезофилл листа; тапетум пыльника; эпидермис рыльца |

Рисунки оригинальные, автономные и схематические. Физический масштаб не измерялся. Книжные лёгкие паука не подменяются трахеями насекомых; лёгкие ящерицы не изображаются человеческим альвеолярным деревом; у дождевого червя показан тифлозоль, а не ворсинки млекопитающих. Спороциты 2n формируют споры n после мейоза.

### Интеграция

- Компонент: src/LektrusBioLineageMicroscopy.tsx.
- Маршруты: src/LektrusBioNewSpeciesArt.tsx и src/LektrusBioFurtherSpeciesArt.tsx.
- Уровни организма, системы и органа сохранены из прежней реализации.
- 72 интерактивные точки расположены отдельно для каждого из 24 клеточных сценариев; структура фактов и клавиатурная доступность сохранены.
- Тест scripts/test-lektrus-bio-lineage-microscopy.mjs включён в test:biology-atlas и GitHub Actions.

Добавление теста в CI не заменяет реального запуска TypeScript-сборки. Результаты проверяются отдельно.
