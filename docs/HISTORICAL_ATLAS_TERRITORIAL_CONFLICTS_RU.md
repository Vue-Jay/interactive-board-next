## Порядок

Уточнение пользователя 17.11.2026: требуется отдельный полный проход реального браузера по каждой территории каждого года. Результаты годовых кликов сохраняются в `lektrus-annual-browser-shard-*`, а сводка ошибок — `lektrus-annual-browser-complete-ledger`. Этот реестр остаётся очередью исторической проверки; совпадения и технические ошибки из годовых прогонов добавлять сюда с конкретными годами и идентификаторами, до пакетной правки. Не считать клик доказательством исторической достоверности.

1. Взять следующую открытую политическую пару по убыванию последнего затронутого года. Изучать каждую уникальную геометрию и интервал; одинаковые факты исследовать совместно. Для каждого случая записать факт, даты, источник, компоненты и предложенную корректировку.
2. Статусы: **кандидат** (по умолчанию у всех записей снимка), **факт подтверждён / требуется решение**, **подтверждённая ошибка**, **допустимое историческое наложение / требуется различение слоёв**, **исправление внесено / регрессия ожидается**, **закрыт**. Последний статус только после исторической сверки, проверки затронутых годовых границ и прогона на новом наборе. Отдельно фиксировать спорные/недостаточно известные контуры; не объявлять их закрытыми.
3. После разбора очередного большого пакета применить только подтверждённые согласованные правила и добавить проверки граничных годов/контуров. Один пакет — одна отправка и один полноценный регрессионный прогон; исследовать следующие записи в процессе уже запущенного CI. Поддерживать неизменность исходника и корректность не связанных с ошибкой частей.
4. Не переключаться на связи, пробелы, UI или публикацию до разбора политических территориальных конфликтов. Полный выпуск — по отдельным обязательным этапам канонического плана.
