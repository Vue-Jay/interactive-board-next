# Lektrus: критерии завершения школьной химической лаборатории

Статус: **финальная приёмка, расширение функциональности остановлено**.

## Границы версии 1.0

Школьный учебный симулятор, а не исследовательский термодинамический пакет. Входные данные задаются самой лабораторией, расчёты воспроизводимы. Допускаются документированные школьные приближения и округления. Не допускаются появление вещества из ничего, исчезновение осадка, задвоение газа, самопроизвольный запуск подготовленного опыта, запись ещё не протёкшей реакции и разрушение соседних объектов доски.

**До выпуска не добавляем:** новые виды опытов, вещества, реакционные семейства, приборы, режимы отображения или новые экраны. Расширение базы физических констант не является блокером само по себе: неизвестные точные значения помечаются как неизвестные/приближённые, а не подменяются выдуманными.

## Автоматическая приёмка, обязательна перед каждым релизом

Единый сценарий: npm run test:lab-acceptance. Он проверяет настоящие модели, помещает таблицу результатов в сводку GitHub Actions и завершает CI ошибкой при провале любого обязательного опыта.

| № | Сценарий | Критерий |
| --- | --- | --- |
| LAB-01 | Каталог | 180 реагентов, сбалансированные проверенные уравнения и рабочие режимы |
| LAB-02 | Осаждение | AgCl остаётся в сосуде, индикатор его не удаляет, уравнение только после завершения |
| LAB-03 | Фильтрация | AgCl остаётся на фильтре, NaNO3 проходит, сумма масс сохраняется |
| LAB-04 | Титрование | HCl/NaOH: эквивалентность при рассчитанном объёме, правильный остаток в бюретке |
| LAB-05 | Пауза и переливание | Новая реакция не начинается на паузе, осадок растёт постепенно, запись после завершения |
| LAB-06 | Газ и сбор | CO2 поступает порциями, повторное подключение не удваивает газ |
| LAB-07 | Тепло | Измеренная нейтрализация повышает температуру |
| LAB-08 | Выпаривание | Вода при нагреве испаряется, объём не становится отрицательным |
| LAB-09 | Растворение | KNO3 делится между фазами без потерь массы |
| LAB-10 | Синхронизация | Независимые правки сохраняются, очистка стола не отменяется устаревшим состоянием |
| LAB-11 | Сохранение | Лаборатория открывается заново без повреждения других объектов доски |

**Каждый тест выполняется отдельно:** отказ одного сценария не скрывает результат остальных. Число проходящих проверок само по себе не означает готовность выпуска.

## Что ещё нужно закрыть

1. **Консистентность модели.** Проверить на крайних количествах и последовательных реакциях процессы, для которых текущая сеть использует школьные приближения. Чинить только подтверждённые ошибки и добавлять для них регрессию.
2. **Визуализация и приборы.** Проверить в браузере, что выделение, нижний слой осадка, эффекты газа/кипения/испарения, шкафы, штатив, переливание и пауза не перекрываются и работают без двойных действий.
3. **Мобильная и совместная работа.** Отдельная ручная приёмка на телефоне и компьютере, в портретной и полноэкранной ориентации, при медленной сети и одновременных изменениях. Автотесты её не заменяют.
4. **Завершение.** При PASS всех обязательных проверок и отсутствии критических ошибок фиксируем версию лаборатории; некритические усовершенствования переносим в будущую версию.

## Правило остановки

Симулятор считается завершённым для школьного использования, когда все 11 автоматических сценариев зелёные, остальные регрессионные тесты и сборки зелёные, вручную пройдены основные опыты и мобильная/совместная приёмка, а открытых ошибок, способных потерять опыт, испортить расчёт или заблокировать интерфейс, нет.

**Следующий этап после первого приёмочного прогона:** устранение только конкретных ошибок, найденных при приёмке; без разработки дополнительных функций.
