# Telegram-редакция Lektrus

Админка → Новости и обновления → Telegram. Посты создаются по фактам: новая опубликованная новость сайта, а по желанию также запланированные/начатые/завершённые техработы. Нет ежедневного контент-плана. Черновики, расписание, журнал отправки и ручная публикация доступны в редакции. Автоматическая отправка выключена по умолчанию.

## Подключение

1. В Telegram откройте [@BotFather](https://t.me/BotFather), создайте отдельного бота командой /newbot.
2. В канале [@lektrus](https://t.me/lektrus) добавьте бота администратором с правом публиковать сообщения. Не выдавайте лишних прав.
3. В настройках проекта Amvera добавьте секрет LEKTRUS_TELEGRAM_BOT_TOKEN с выданным токеном и переменную LEKTRUS_TELEGRAM_CHANNEL=@lektrus. Токен не добавляйте в Git, чат, клиентский код или скриншоты.
4. Перезапустите проект с новой конфигурацией и применённой миграцией 106_telegram_editor.sql. В админке нажмите «Проверить подключение». Сервер проверяет канал, личность и права бота.
5. Включите новые новости сайта; сначала оставьте автоматическую отправку выключенной. Проверьте черновик перед отправкой. Когда всё готово, можно разрешить автопубликацию. Старые новости не отправляются автоматически.

## Необязательный AI

Публикация новостей не требует AI и не имеет расходов на генерацию. Для ручного создания черновиков и иллюстраций задайте секрет LEKTRUS_OPENAI_API_KEY и переменные LEKTRUS_OPENAI_TEXT_MODEL и LEKTRUS_OPENAI_IMAGE_MODEL с доступными вашему API-проекту моделями Responses и Image API соответственно. Не включайте генерацию без бюджета API. Дневной предел — 10 текстовых и 3 графических запроса, включая неуспешные. Модель создаёт только черновик; иллюстрации не заменяют оригинальный логотип. Текст с изображением ограничен 1000 символами. После успешной отправки JPEG удаляется из базы.

## Надёжность

Очередь в PostgreSQL, обработка каждые 15 секунд при настроенном Telegram. Подтверждённые сообщения не пересылаются. При потере ответа на отправку запись получает статус «Проверить вручную», автоматического повтора нет. При смене бота или канала повторно подтвердите подключение: очереди переводятся в черновики. Отключение автопубликации снимает ещё не отправленные автоматические записи с расписания.

При полном падении сервера сам сервер не сможет опубликовать сообщение о сбое — для этого требуется независимый внешний мониторинг.
