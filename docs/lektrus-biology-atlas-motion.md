# Lektrus · Биологический атлас: иллюстрации и анимации

## Результат итерации

Интерактивные схемы пяти организмов с переменной глубиной строения получили:
- насыщенную палитру, многослойные SVG-заливки, фоновую структуру и светотеневые акценты без загрузки сторонних изображений;
- плавную смену иллюстрации при выборе органа, клетки или органоида;
- независимый от навигационных точек слой векторной анимации;
- управление **Пауза / Пуск** для непрерывных процессов;
- кнопку **Показать / Повторить** для одноразовых событий;
- автоматическое отключение движения при `prefers-reduced-motion: reduce`;
- пояснение и отдельную проверяемую ссылку рядом с каждой анимацией.

Анимация отрисовывается CSS/SVG и не использует таймеров, Canvas, сторонних библиотек, аудио или фоновой синхронизации. Интерактивные точки остаются кликабельными на мыши, касании и клавиатуре, поскольку анимационный слой имеет `pointerEvents="none"`. Координаты рисунка остаются условными, не являются микрометрическими измерениями.

## Десять визуальных процессов

| Группа | Иллюстрация | Поведение | Биологическое ограничение |
| --- | --- | --- | --- |
| Губка | Движение воды через поры и выводные отверстия | Цикл | Путь воды схематичен, не реальная скорость |
| Губка | Биение жгутика хоаноцита | Цикл | Показана функция, а не фактическая пространственная траектория |
| Гидра | Небольшие движения щупалец | Цикл | Скорость условна |
| Гидра | Выстрел стрекательной капсулы | Однократно по кнопке | Одна капсула не выстреливает бесконечно |
| Кукушкин лён | Гибкость листовидных структур | Цикл | Колебание не обозначает активный рост |
| Кукушкин лён | Выброс спор из зрелой коробочки | Однократно по кнопке | Показана зрелая стадия, не постоянная функция |
| Хламидомонада | Работа двух жгутиков | Цикл | Не точное 3D-биение |
| Хламидомонада | Фоточувствительность глазка | Цикл подсветки | Световой луч условен |
| Спирогира | Подсветка спиральных хлоропластов | Цикл подсветки | Не обозначает вращение хлоропластов |
| Спирогира | Конъюгационная трубка и перемещение содержимого | Однократно по кнопке | Процесс существенно длиннее демонстрации |

Смысловой каталог процесса и привязка к точным узлам находятся в `src/lektrusBioAtlasMotion.ts`, SVG-сцена в `src/LektrusBioMotionLayer.tsx`. В представлении `src/LektrusBioAlternativeView.tsx` процесс выбирается по **настоящему ID структуры**, а не только по имени организма. Если у структуры нет корректной визуализации, слой не рисует ложную анимацию.

## Источники

- [OpenStax Biology 2e: Phylum Porifera](https://openstax.org/books/biology-2e/pages/28-1-phylum-porifera): водные потоки, хоаноциты.
- [OpenStax Biology 2e: Phylum Cnidaria](https://openstax.org/books/biology-2e/pages/28-2-phylum-cnidaria): щупальца и нематоцисты.
- [OpenStax Biology 2e: Bryophytes](https://openstax.org/books/biology-2e/pages/25-3-bryophytes): диплоидный спорофит и распространение гаплоидных спор.
- [NCBI/PMC: Chlamydomonas eyespot](https://pmc.ncbi.nlm.nih.gov/articles/PMC3811559/): глазок и связанные структуры.
- [NIOS Biology: Spirogyra](https://allenwebsite-general.s3.ap-south-1.amazonaws.com/nios/download/sr-secondary/Biology_314_Book2.pdf): хлоропласты и конъюгация.

Все рисунки оригинальные, схематические, **не фотографии и не масштабные модели**, а время воспроизведения не калибровано по экспериментальным наблюдениям.

## Проверка

`npm run test:biology-atlas` включает `test-lektrus-bio-motion.mjs` и проверяет соответствие 10 процессов видовым узлам, запрет бесконечного цикла одноразовых реакций, переключатели управления, доступность точек, ссылки, `prefers-reduced-motion` и синтаксис TSX. GitHub Actions дополнительно выполняет полный TypeScript/Vite build.

Следующие задачи: рисунки анатомических пластин с реально различимыми тканевыми слоями на всех 17 видах, просмотр настоящих лицензированных микрофотографий с линейкой масштаба, задания по интерактивным анимациям.
