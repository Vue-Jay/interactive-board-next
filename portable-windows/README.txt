LEKTRUS - PORTABLE WINDOWS VERSION

1. Extract the entire ZIP archive to a folder.
2. Double-click "Запустить Lektrus.bat".
3. Your default browser opens http://localhost:4173/
4. Keep the command window open while testing.
5. To stop the server, close the command window.

No Node.js, Python or developer tools are required on the tester's PC.
Windows PowerShell is included in supported Windows installations.
Only your PC can access the local server (localhost).
Account login and real-time synchronization still need an internet connection
and a correctly configured Supabase backend.
If Windows displays a security warning, inspect the source scripts before running.
If port 4173 is occupied, close the other application using that port.
