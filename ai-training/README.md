# Локальный классификатор предметов

Модель распознаёт школьный предмет по теме запроса. Она не сочиняет текст сама: после распознавания задания формирует существующий локальный генератор Lectrus.

## Обучение

Нужен Python 3.12+; дополнительных библиотек и доступа к интернету не требуется.

```powershell
npm run train:ai-subject-model
npm run build
```

Скрипт берёт темы из `subject_topics.json`, расширяет их двадцатью вариантами формулировок и обучает мультиномиальный классификатор со словесными, символьными и соседними парами слов. Проверка отдельно измеряет новые формулировки знакомых тем и темы, целиком исключённые из обучения. Обучающая и проверочная выборки детерминированы.

Текущий корпус содержит **2 055 учебных тем по 11 предметам**: математика — 342, физика — 153, химия — 112, биология — 181, география — 205, русский язык — 462, литература — 60, история — 348, обществознание — 72, информатика — 60, иностранный язык — 60. Модель содержит 8 000 признаков и занимает **1 339 573 байта** (около 1 308,2 КиБ). Для каждого предсказанного предмета применяется собственный порог, рассчитанный на проверочных примерах этого предмета; 22 общих и неоднозначных формулировки используются только для калибровки отказа от угадывания. Старые метрики обучения из прошлой версии удалены: актуальные результаты публикуются в [`ROADMAP.md`](./ROADMAP.md), включая ограничение охвата прямого классификатора. Точная проверка каталога распознаёт 2 055/2 055 названий; она не доказывает понимание любых свободных формулировок. Неоднозначные и низкоуверенные запросы должны уточняться.

Для каждой темы доступен предметный выход, а специализированные генераторы дают конкретные задания для всех тем четырёх приоритетных предметов: математика **342/342**, физика **153/153**, химия **112/112**, русский язык **462/462**. Автоматическая связка кодов программы и классов проверяется `npm run eval:ai-curriculum`; полный список источников, кодов и годовых планов приведён в [`curriculum_grade_map.json`](./curriculum_grade_map.json) и дорожной карте. Структурная проверка обнаруживает пропуски и ошибки параметров, но не оценивает научную и педагогическую корректность. Независимая оценка преподавателем пакета из 36 заданий ещё нужна.

План дальнейшей работы и конечные критерии выпуска помощника находятся в [`ROADMAP.md`](./ROADMAP.md). Корпус тем — карта покрытия, не полный перечень всех федеральных результатов обучения; до достижения выпускных критериев помощник не должен заявляться как покрывающий всю школьную программу.

Чтобы повторить структурную проверку распознавания тем, параметров запроса и комплектов заданий, запустите `npm run eval:ai-curriculum`. Она выявляет пропуски структуры и повторения, но не заменяет содержательную оценку учителем.

В приложении модель загружается с хостинга Lectrus только при открытии ИИ-помощника, затем сохраняется в браузере для следующих запусков. Новая версия модели автоматически получает новый ключ кэша. Классификация выполняется в браузере. Внешний API, сервер модели и запросы к Supabase для распознавания не используются. Сохранение материалов и работа доски продолжают использовать обычное хранилище приложения.
