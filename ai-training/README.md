# Локальный классификатор предметов

Модель распознаёт школьный предмет по теме запроса. Она не сочиняет текст сама: после распознавания задания формирует существующий локальный генератор Lectrus.

## Обучение

Нужен Python 3.12+; дополнительных библиотек и доступа к интернету не требуется.

```powershell
npm run train:ai-subject-model
npm run build
```

Скрипт берёт темы из `subject_topics.json`, расширяет их двенадцатью вариантами формулировок и обучает мультиномиальный классификатор с символьными и словесными признаками. Проверка отдельно измеряет новые формулировки знакомых тем и темы, целиком исключённые из обучения. Обучающая и проверочная выборки детерминированы.

Текущий корпус содержит 682 учебные темы по 11 предметам: математика — 70, обществознание — 72, остальные девять предметов — по 60. Последний прогон обучался на 5 450 обучающих, 1 090 отложенных формулировках и 1 644 отложенных формулировках новых тем; модель весит 1,18 МиБ. Классификатор показал 95,7% точности на новых формулировках знакомых тем и 70,1% на темах, целиком исключённых из обучения. При пороге уверенности 7 он принимает 40,2% запросов со знакомыми темами с точностью 100%, а на новых темах — 16,1% с точностью 99,2%. Низкоуверенные запросы должны уточняться. Точные темы из корпуса сверяются по компактному индексу: 682/682 распознаны правильно. Это проверка на собственном ограниченном корпусе, а не доказательство понимания любого пользовательского запроса.

Генератор отдельно прошёл прогон по всем 682 темам: на каждую тему сформировано по 15 заданий с ответами, без повторяющихся формулировок и без подмены предмета. Темы математики для 1 класса сопоставлены с 14 кодами федеральной программы; 150 заданий дополнительно прошли арифметические и возрастные проверки. Во время 682 пробных генераций при заблокированной сети после загрузки модели сетевых обращений не было; проверка холодного запуска приложения без сети ещё не выполнена. Добавлены конкретные проверяемые расчётные задания по механике, теплоте, электричеству, химическим растворам и количеству вещества, генетике и ориентированию. При узкой теме используются безопасные форматы практики с критериями проверки. Параметры запроса сверяются на примерах количества, класса, сложности и типа работы. Это не означает, что модель сочиняет произвольные ответы: задания формируют проверяемые шаблоны и генераторы приложения.

План дальнейшей работы и конечные критерии выпуска помощника находятся в [`ROADMAP.md`](./ROADMAP.md). Корпус тем — карта покрытия, не полный перечень всех федеральных результатов обучения; до достижения выпускных критериев помощник не должен заявляться как покрывающий всю школьную программу.

Чтобы повторить структурную проверку распознавания тем, параметров запроса и комплектов заданий, запустите `npm run eval:ai-curriculum`. Она выявляет пропуски структуры и повторения, но не заменяет содержательную оценку учителем.

В приложении модель загружается с хостинга Lectrus только при открытии ИИ-помощника, затем сохраняется в браузере для следующих запусков. Новая версия модели автоматически получает новый ключ кэша. Классификация выполняется в браузере. Внешний API, сервер модели и запросы к Supabase для распознавания не используются. Сохранение материалов и работа доски продолжают использовать обычное хранилище приложения.
