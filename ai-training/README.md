# Локальный классификатор предметов

Модель распознаёт школьный предмет по теме запроса. Она не сочиняет текст сама: после распознавания задания формирует существующий локальный генератор Lectrus.

## Обучение

Нужен Python 3.12+; дополнительных библиотек и доступа к интернету не требуется.

```powershell
npm run train:ai-subject-model
npm run build
```

Скрипт берёт темы из `subject_topics.json`, расширяет их двенадцатью вариантами формулировок и обучает мультиномиальный классификатор со словесными, символьными и соседними парами слов. Проверка отдельно измеряет новые формулировки знакомых тем и темы, целиком исключённые из обучения. Обучающая и проверочная выборки детерминированы.

Текущий корпус содержит 1 598 учебных тем по 11 предметам: математика — 342, физика — 98, химия — 112, биология — 181, география — 205, русский язык — 60, литература — 60, история — 348, обществознание — 72, информатика — 60, иностранный язык — 60. Последний прогон обучался на 22 950 примерах. Калибровка: 326 формулировок знакомых тем и 3 280 примеров новых тем; финальная проверка: 2 224 и 3 180 примеров. Размер модели — 1 103 КиБ, словарь — 8 000 признаков. На финальных наборах классификатор показал 96,9% точности на новых формулировках знакомых тем и 81,6% на новых темах. Порог 3,557 подобран для целевой точности уверенного ответа не менее 99%; уверенно принимается 79,7% запросов знакомых тем и 60,1% новых тем. Точность принятых ответов: 99,8% на знакомых темах и 96,9% на новых; цель 99% для новых тем пока не достигнута. Неоднозначные и низкоуверенные запросы должны уточняться. Точные темы из корпуса сверяются по индексу: 1 598/1 598 распознаны правильно. Это проверка на собственном ограниченном корпусе, а не доказательство понимания любого пользовательского запроса.

Для каждой из 1 598 тем сформирован базовый предметный выход. История 5–11 классов сопоставлена со всеми 314 кодами содержания федеральных программ 2025 года. Математика 1–11 классов сопоставлена со всеми 343 кодами; физика 7–9 классов — со всеми 153. По химии федеральные программы 2025 года сверены по всем 88 элементам содержания (25, 25, 19 и 19 по классам 8–11). По биологии сопоставлены все 162 кода базовых федеральных программ 2025 года для 5–11 классов (18, 13, 15, 28, 34, 33 и 21). По географии сопоставлены все 146 кодов базовых программ 2025 года по классам 5–11 (18, 21, 22, 25, 18, 30 и 12); каталог географии расширен до 205 тем. Источники: [биология 5–9 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_biologiya_5-9_baza.pdf), [биология 10–11 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_biologiya_10_11_baz.pdf), [география 5–9 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_geografiya-5-9.pdf), [география 10–11 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_geografiya_10_11_baz.pdf), [химия 8–9 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_himiya_8-9_baza.pdf) и [химия 10–11 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_himiya_10_11_baz.pdf). Нестандартные и олимпиадные запросы по всем предметам должны формироваться тем же способом из обычного запроса пользователя, без отдельного режима или визуального выделения. Проверены 80 формулировок, сохраняющих заданную тему и критерии проверки. Это структурные проверки, не экспертная оценка открытых ответов.

План дальнейшей работы и конечные критерии выпуска помощника находятся в [`ROADMAP.md`](./ROADMAP.md). Корпус тем — карта покрытия, не полный перечень всех федеральных результатов обучения; до достижения выпускных критериев помощник не должен заявляться как покрывающий всю школьную программу.

Чтобы повторить структурную проверку распознавания тем, параметров запроса и комплектов заданий, запустите `npm run eval:ai-curriculum`. Она выявляет пропуски структуры и повторения, но не заменяет содержательную оценку учителем.

В приложении модель загружается с хостинга Lectrus только при открытии ИИ-помощника, затем сохраняется в браузере для следующих запусков. Новая версия модели автоматически получает новый ключ кэша. Классификация выполняется в браузере. Внешний API, сервер модели и запросы к Supabase для распознавания не используются. Сохранение материалов и работа доски продолжают использовать обычное хранилище приложения.
