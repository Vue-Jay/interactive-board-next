# Локальный классификатор предметов

Модель распознаёт школьный предмет по теме запроса. Она не сочиняет текст сама: после распознавания задания формирует существующий локальный генератор Lectrus.

## Обучение

Нужен Python 3.12+; дополнительных библиотек и доступа к интернету не требуется.

```powershell
npm run train:ai-subject-model
npm run build
```

Скрипт берёт темы из `subject_topics.json`, расширяет их двенадцатью вариантами формулировок и обучает мультиномиальный классификатор со словесными, символьными и соседними парами слов. Проверка отдельно измеряет новые формулировки знакомых тем и темы, целиком исключённые из обучения. Обучающая и проверочная выборки детерминированы.

Текущий корпус содержит 1 453 учебные темы по 11 предметам: математика — 342, физика — 98, химия — 112, обществознание — 72, история — 348, биология — 181, география, русский язык, литература, информатика и иностранный язык — по 60. Последний прогон обучался на 20 862 примерах. Калибровка: 296 формулировок знакомых тем и 2 980 примеров новых тем; финальная проверка: 2 022 и 2 900 примеров. Размер модели — 1023 КиБ, словарь — 8 000 признаков. На финальных наборах классификатор показал 97,9% точности на новых формулировках знакомых тем и 82,1% на новых темах. Порог 3,838 подобран для целевой точности уверенного ответа не менее 99%; уверенно принимается 80,4% запросов знакомых тем и 56,1% новых тем. Точность принятых ответов: 100% на знакомых темах и 97,6% на новых; цель 99% для новых тем пока не достигнута, поэтому неоднозначные и низкоуверенные запросы должны уточняться. Точные темы из корпуса сверяются по индексу: 1 453/1 453 распознаны правильно. Это проверка на собственном ограниченном корпусе, а не доказательство понимания любого пользовательского запроса.

Для каждой из 1 453 тем сформирован базовый предметный выход. История 5–11 классов сопоставлена со всеми 314 кодами содержания федеральных программ 2025 года. Математика 1–11 классов сопоставлена со всеми 343 кодами; физика 7–9 классов — со всеми 153. По химии федеральные программы 2025 года сверены по всем 88 элементам содержания: 25/25 кодов 8 класса, 25/25 9 класса, 19/19 10 класса и 19/19 11 класса. Каталог химии включает 112 тем, 109 распределены по классам 8–11, три отмечены как расширение. По биологии сопоставлены все 162 кода базовых федеральных программ 2025 года для 5–11 классов (18, 13, 15, 28, 34, 33 и 21 по классам). Источники: [биология 5–9 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_biologiya_5-9_baza.pdf), [биология 10–11 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_biologiya_10_11_baz.pdf), [химия 8–9 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_himiya_8-9_baza.pdf) и [химия 10–11 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_himiya_10_11_baz.pdf). Нестандартные и олимпиадные запросы по всем предметам должны формироваться тем же способом из обычного запроса пользователя, без отдельного режима или визуального выделения. Проверены 80 формулировок, сохраняющих заданную тему и критерии проверки. Это структурные проверки, не экспертная оценка открытых ответов.

План дальнейшей работы и конечные критерии выпуска помощника находятся в [`ROADMAP.md`](./ROADMAP.md). Корпус тем — карта покрытия, не полный перечень всех федеральных результатов обучения; до достижения выпускных критериев помощник не должен заявляться как покрывающий всю школьную программу.

Чтобы повторить структурную проверку распознавания тем, параметров запроса и комплектов заданий, запустите `npm run eval:ai-curriculum`. Она выявляет пропуски структуры и повторения, но не заменяет содержательную оценку учителем.

В приложении модель загружается с хостинга Lectrus только при открытии ИИ-помощника, затем сохраняется в браузере для следующих запусков. Новая версия модели автоматически получает новый ключ кэша. Классификация выполняется в браузере. Внешний API, сервер модели и запросы к Supabase для распознавания не используются. Сохранение материалов и работа доски продолжают использовать обычное хранилище приложения.
