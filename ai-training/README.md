# Локальный классификатор предметов

Модель распознаёт школьный предмет по теме запроса. Она не сочиняет текст сама: после распознавания задания формирует существующий локальный генератор Lectrus.

## Обучение

Нужен Python 3.12+; дополнительных библиотек и доступа к интернету не требуется.

```powershell
npm run train:ai-subject-model
npm run build
```

Скрипт берёт темы из `subject_topics.json`, расширяет их двенадцатью вариантами формулировок и обучает мультиномиальный классификатор с символьными и словесными признаками. Проверка отдельно измеряет новые формулировки знакомых тем и темы, целиком исключённые из обучения. Обучающая и проверочная выборки детерминированы.

Текущий корпус содержит 975 учебных тем по 11 предметам: математика — 342, обществознание — 72, история — 81, остальные восемь предметов — по 60. Последний прогон обучался на 14 004 примерах. Калибровка: 198 формулировок знакомых тем и 2 000 примеров новых тем; финальная проверка: 1 358 и 1 940 примеров. Размер модели — 1 498 518 байт (около 1,43 МиБ), словарь — 5 800 признаков. На финальных наборах классификатор показал 97,1% точности на новых формулировках знакомых тем и 79,7% на новых темах. Порог 7,832 подобран для не менее 99% точности калибровочной выборки; уверенно принимается 49,2% запросов знакомых тем и 25,7% новых тем, точность принятых ответов — 100% в обеих выборках. Остальные запросы должны уточняться. Точные темы из корпуса сверяются по индексу: 975/975 распознаны правильно. Это проверка на собственном ограниченном корпусе, а не доказательство понимания любого пользовательского запроса.

Для каждой из 975 тем сформирован базовый предметный выход; наборные и числовые проверки запускаются отдельно по темам, где есть проверяемые генераторы. Темы математики 1–11 классов сопоставлены с 14/14, 19/19, 23/23, 21/21, 25/25, 34/34, 39/39, 48/48, 51/51, 34/34 и 35/35 кодами федеральной программы; поэлементно проверены все 69 кодов старшей школы; проверены 150 заданий для 1 класса, 315 для 2, 195 генераций по 13 темам 3 класса и 165 генераций по 11 темам 4 класса. Для 6 класса отдельно создаются и проверяются 15 заданий на симметрию и 15 на периметр, включая пересчёт каждого ответа. Добавлены 15 нестандартных математических задач с проверкой правильности ответов; ещё 15 запросов по принципу Дирихле, инвариантам и комбинаторике проверяют, что тема и класс не теряются. 150 заданий математики 1 класса прошли арифметические и возрастные проверки. Во время 975 пробных генераций при заблокированной сети после загрузки модели сетевых обращений не было; проверка холодного запуска приложения без сети ещё не выполнена. Добавлены конкретные проверяемые расчётные задания по механике, теплоте, электричеству, химическим растворам и количеству вещества, генетике и ориентированию. Для 12 тем, посвящённых 11 произведениям, генератор проверяет автора и жанр по федеральным программам литературы для 5–9 и 10–11 классов; эти 12 ключей проверяются в приёмочном прогоне. При узкой теме используются безопасные форматы практики с критериями проверки. Параметры запроса сверяются на примерах количества, класса, сложности и типа работы; нестандартная или олимпиадная формулировка воспринимается как часть обычного запроса генерации. Это не означает, что модель сочиняет произвольные ответы: задания формируют проверяемые шаблоны и генераторы приложения.

План дальнейшей работы и конечные критерии выпуска помощника находятся в [`ROADMAP.md`](./ROADMAP.md). Корпус тем — карта покрытия, не полный перечень всех федеральных результатов обучения; до достижения выпускных критериев помощник не должен заявляться как покрывающий всю школьную программу.

Чтобы повторить структурную проверку распознавания тем, параметров запроса и комплектов заданий, запустите `npm run eval:ai-curriculum`. Она выявляет пропуски структуры и повторения, но не заменяет содержательную оценку учителем.

В приложении модель загружается с хостинга Lectrus только при открытии ИИ-помощника, затем сохраняется в браузере для следующих запусков. Новая версия модели автоматически получает новый ключ кэша. Классификация выполняется в браузере. Внешний API, сервер модели и запросы к Supabase для распознавания не используются. Сохранение материалов и работа доски продолжают использовать обычное хранилище приложения.
