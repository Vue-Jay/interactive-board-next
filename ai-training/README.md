# Локальный классификатор предметов

Модель распознаёт школьный предмет по теме запроса. Она не сочиняет текст сама: после распознавания задания формирует существующий локальный генератор Lectrus.

## Обучение

Нужен Python 3.12+; дополнительных библиотек и доступа к интернету не требуется.

```powershell
npm run train:ai-subject-model
npm run build
```

Скрипт берёт темы из `subject_topics.json`, расширяет их двенадцатью вариантами формулировок и обучает мультиномиальный классификатор со словесными, символьными и соседними парами слов. Проверка отдельно измеряет новые формулировки знакомых тем и темы, целиком исключённые из обучения. Обучающая и проверочная выборки детерминированы.

Текущий корпус содержит 1 332 учебные темы по 11 предметам: математика — 342, физика — 98, химия — 112, обществознание — 72, история — 348, остальные шесть предметов — по 60. Последний прогон обучался на 19 134 примерах. Калибровка: 272 формулировки знакомых тем и 2 720 примеров новых тем; финальная проверка: 1 854 и 2 660 примеров. Размер модели — 996 КиБ, словарь — 8 000 признаков. На финальных наборах классификатор показал 97,8% точности на новых формулировках знакомых тем и 82,4% на новых темах. Порог 5,011 подобран для целевой точности уверенного ответа не менее 99%; уверенно принимается 72,0% запросов знакомых тем и 46,8% новых тем. Точность принятых ответов в этих выборках — 100%; остальные запросы должны уточняться. Точные темы из корпуса сверяются по индексу: 1 332/1 332 распознаны правильно. Это проверка на собственном ограниченном корпусе, а не доказательство понимания любого пользовательского запроса.

Для каждой из 1 332 тем сформирован базовый предметный выход. История 5–11 классов сопоставлена со всеми 314 кодами содержания федеральных программ 2025 года. Математика 1–11 классов сопоставлена со всеми 343 кодами; физика 7–9 классов — со всеми 153. По химии федеральные программы 2025 года сверены по всем элементам содержания: 25/25 кодов 8 класса, 25/25 9 класса, 19/19 10 класса и 19/19 11 класса. Каталог химии вырос до 112 тем, 109 распределены по классам 8–11, три отмечены как расширение. Источники: [федеральная программа химии 8–9 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_himiya_8-9_baza.pdf) и [федеральная программа химии 10–11 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_himiya_10_11_baz.pdf). Нестандартные запросы по десяти предметам кроме математики проходят обычный путь генерации с предметными сценариями рассуждения; отдельного режима или названия нет. Проверены 80 формулировок, сохраняющих пользовательскую тему и критерии проверки. Это структурные проверки, не экспертная оценка открытых ответов.

План дальнейшей работы и конечные критерии выпуска помощника находятся в [`ROADMAP.md`](./ROADMAP.md). Корпус тем — карта покрытия, не полный перечень всех федеральных результатов обучения; до достижения выпускных критериев помощник не должен заявляться как покрывающий всю школьную программу.

Чтобы повторить структурную проверку распознавания тем, параметров запроса и комплектов заданий, запустите `npm run eval:ai-curriculum`. Она выявляет пропуски структуры и повторения, но не заменяет содержательную оценку учителем.

В приложении модель загружается с хостинга Lectrus только при открытии ИИ-помощника, затем сохраняется в браузере для следующих запусков. Новая версия модели автоматически получает новый ключ кэша. Классификация выполняется в браузере. Внешний API, сервер модели и запросы к Supabase для распознавания не используются. Сохранение материалов и работа доски продолжают использовать обычное хранилище приложения.
