# Локальный классификатор предметов

Модель распознаёт школьный предмет по теме запроса. Она не сочиняет текст сама: после распознавания задания формирует существующий локальный генератор Lectrus.

## Обучение

Нужен Python 3.12+; дополнительных библиотек и доступа к интернету не требуется.

```powershell
npm run train:ai-subject-model
npm run build
```

Скрипт берёт темы из `subject_topics.json`, расширяет их двенадцатью вариантами формулировок и обучает мультиномиальный классификатор со словесными, символьными и соседними парами слов. Проверка отдельно измеряет новые формулировки знакомых тем и темы, целиком исключённые из обучения. Обучающая и проверочная выборки детерминированы.

Текущий корпус содержит 1 158 учебных тем по 11 предметам: математика — 342, физика — 98, обществознание — 72, история — 226, остальные семь предметов — по 60. Последний прогон обучался на 16 632 примерах. Калибровка: 236 формулировок знакомых тем и 2 360 примеров новых тем; финальная проверка: 1 612 и 2 320 примеров. Размер модели — 955,6 КиБ, словарь — 8 000 признаков. Словарь признаков хранится один раз, веса предметов — компактными массивами. На финальных наборах классификатор показал 98,1% точности на новых формулировках знакомых тем и 80,6% на новых темах. Порог 2,961 подобран для целевой точности уверенного ответа не менее 99%; уверенно принимается 87,3% запросов знакомых тем и 62,9% новых тем. Точность принятых ответов — 99,9% и 96,1% соответственно; остальные запросы должны уточняться. Точные темы из корпуса сверяются по индексу: 1 158/1 158 распознаны правильно. Это проверка на собственном ограниченном корпусе, а не доказательство понимания любого пользовательского запроса.

Для каждой из 1 158 тем сформирован базовый предметный выход; история 5–9 классов поэлементно сопоставлена со всеми 26, 42, 36, 35 и 53 кодами содержания федеральной программы 2025 года; наборные и числовые проверки запускаются отдельно по темам, где есть проверяемые генераторы. Темы математики 1–11 классов сопоставлены с 14/14, 19/19, 23/23, 21/21, 25/25, 34/34, 39/39, 48/48, 51/51, 34/34 и 35/35 кодами федеральной программы; поэлементно проверены все 69 кодов старшей школы; проверены 150 заданий для 1 класса, 315 для 2, 195 генераций по 13 темам 3 класса и 165 генераций по 11 темам 4 класса. Для 6 класса отдельно создаются и проверяются 15 заданий на симметрию и 15 на периметр, включая пересчёт каждого ответа. Добавлены 15 нестандартных математических задач с проверкой правильности ответов; ещё 15 запросов по принципу Дирихле, инвариантам и комбинаторике проверяют, что тема и класс не теряются. 150 заданий математики 1 класса прошли арифметические и возрастные проверки. Во время 1 158 пробных генераций при заблокированной сети после загрузки модели сетевых обращений не было; проверка холодного запуска приложения без сети ещё не выполнена. Добавлены конкретные проверяемые расчётные задания по механике, теплоте, электричеству, химическим растворам и количеству вещества, генетике и ориентированию. Для 12 тем, посвящённых 11 произведениям, генератор проверяет автора и жанр по федеральным программам литературы для 5–9 и 10–11 классов; эти 12 ключей проверяются в приёмочном прогоне. При узкой теме используются безопасные форматы практики с критериями проверки. Параметры запроса сверяются на примерах количества, класса, сложности и типа работы; нестандартная или олимпиадная формулировка воспринимается как часть обычного запроса генерации. Это не означает, что модель сочиняет произвольные ответы: задания формируют проверяемые шаблоны и генераторы приложения.

План дальнейшей работы и конечные критерии выпуска помощника находятся в [`ROADMAP.md`](./ROADMAP.md). Корпус тем — карта покрытия, не полный перечень всех федеральных результатов обучения; до достижения выпускных критериев помощник не должен заявляться как покрывающий всю школьную программу.

Чтобы повторить структурную проверку распознавания тем, параметров запроса и комплектов заданий, запустите `npm run eval:ai-curriculum`. Она выявляет пропуски структуры и повторения, но не заменяет содержательную оценку учителем.

В приложении модель загружается с хостинга Lectrus только при открытии ИИ-помощника, затем сохраняется в браузере для следующих запусков. Новая версия модели автоматически получает новый ключ кэша. Классификация выполняется в браузере. Внешний API, сервер модели и запросы к Supabase для распознавания не используются. Сохранение материалов и работа доски продолжают использовать обычное хранилище приложения.
