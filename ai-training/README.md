# Локальный классификатор предметов

Модель распознаёт школьный предмет по теме запроса. Она не сочиняет текст сама: после распознавания задания формирует существующий локальный генератор Lectrus.

## Обучение

Нужен Python 3.12+; дополнительных библиотек и доступа к интернету не требуется.

```powershell
npm run train:ai-subject-model
npm run build
```

Скрипт берёт темы из `subject_topics.json`, расширяет их двадцатью вариантами формулировок и обучает мультиномиальный классификатор со словесными, символьными и соседними парами слов. Проверка отдельно измеряет новые формулировки знакомых тем и темы, целиком исключённые из обучения. Обучающая и проверочная выборки детерминированы.

Текущий корпус содержит 1 930 учебных тем по 11 предметам: математика — 342, физика — 98, химия — 112, биология — 181, география — 205, русский язык — 392, литература — 60, история — 348, обществознание — 72, информатика — 60, иностранный язык — 60. Последний прогон обучался на 27 720 примерах. Калибровка: 394 формулировки знакомых тем и 3 960 примеров новых тем; финальная проверка: 2 686 и 3 840 примеров. Размер модели — 1 233,5 КиБ, словарь — 8 000 признаков. На независимых финальных наборах классификатор показал 96,0% точности на новых формулировках знакомых тем и 83,8% на новых темах. Порог установлен консервативно по калибровке каждого предполагаемого предмета; при применении общего строгого порога он принимает 68,4% запросов знакомых тем и 52,2% новых. Точность принятых ответов: 99,7% на знакомых темах и 97,8% на новых; цель 99% для новых тем пока не достигнута. Неоднозначные и низкоуверенные запросы должны уточняться. Точные темы из корпуса сверяются по индексу: 1 930/1 930 распознаны правильно. Это проверка на собственном ограниченном корпусе, а не доказательство понимания любого пользовательского запроса.

Для каждой из 1 930 тем сформирован базовый предметный выход. Математика 1–11 классов сопоставлена со всеми 343 кодами; физика 7–9 классов — со всеми 153; химия 8–11 — со всеми 88 кодами (25, 25, 19 и 19 по классам); русский язык — со всеми 267 кодами приложения ОГЭ 5–9 классов и 70 кодами приложения ЕГЭ 10–11 классов. Биология 5–11 классов сопоставлена со всеми 162 кодами базовых федеральных программ 2025 года (18, 13, 15, 28, 34, 33 и 21 по классам); география — со всеми 146 кодами базовых программ 2025 года по классам 5–11 (18, 21, 22, 25, 18, 30 и 12). Источники: [русский язык 5–9 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_russkij-yazyk_5-9.pdf), [русский язык 10–11 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_russkij-yazyk_10_11.pdf), [биология 5–9 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_biologiya_5-9_baza.pdf), [биология 10–11 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_biologiya_10_11_baz.pdf), [география 5–9 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_geografiya-5-9.pdf), [география 10–11 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_geografiya_10_11_baz.pdf), [химия 8–9 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_ooo_frp_himiya_8-9_baza.pdf) и [химия 10–11 классов](https://edsoo.ru/wp-content/uploads/2025/07/2025_soo_frp_himiya_10_11_baz.pdf). Для приоритетных предметов сверка кодов прошла; это не экспертная оценка всех открытых заданий и не подтверждение полноты программ по всем предметам.
По автоматическому структурному показателю задания с конкретным условием и ответом сейчас покрывают 342/342 тем математики, 70/98 физики, 55/112 химии и 126/392 русского языка; остальные темы используют критерии, опирающиеся на учебный источник. Этот показатель не оценивает научную и педагогическую корректность — содержательная экспертная выборка по четырём приоритетным предметам ещё нужна.

План дальнейшей работы и конечные критерии выпуска помощника находятся в [`ROADMAP.md`](./ROADMAP.md). Корпус тем — карта покрытия, не полный перечень всех федеральных результатов обучения; до достижения выпускных критериев помощник не должен заявляться как покрывающий всю школьную программу.

Чтобы повторить структурную проверку распознавания тем, параметров запроса и комплектов заданий, запустите `npm run eval:ai-curriculum`. Она выявляет пропуски структуры и повторения, но не заменяет содержательную оценку учителем.

В приложении модель загружается с хостинга Lectrus только при открытии ИИ-помощника, затем сохраняется в браузере для следующих запусков. Новая версия модели автоматически получает новый ключ кэша. Классификация выполняется в браузере. Внешний API, сервер модели и запросы к Supabase для распознавания не используются. Сохранение материалов и работа доски продолжают использовать обычное хранилище приложения.
