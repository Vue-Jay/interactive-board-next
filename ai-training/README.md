# Локальный классификатор предметов

Модель распознаёт школьный предмет по теме запроса. Она не сочиняет текст сама: после распознавания задания формирует существующий локальный генератор Lectrus.

## Обучение

Нужен Python 3.12+; дополнительных библиотек и доступа к интернету не требуется.

```powershell
npm run train:ai-subject-model
npm run build
```

Скрипт берёт темы из `subject_topics.json`, расширяет их шестью вариантами формулировок, обучает мультиномиальный классификатор с символьными и словесными признаками, затем проверяет его на двух отложенных вариантах запроса для каждой темы. Обучающая и проверочная фразы детерминированы; команда каждый раз воспроизводит один и тот же файл модели в `public/models/aiSubjectIntentModel.json`.

Текущий корпус содержит 330 учебных тем по 11 предметам. Последний прогон обучался на 1 320 формулировках, проверялся на 660 и показал точность 91,4% на отложенных вариантах формулировок знакомых тем. Это проверка определения предмета, а не качества сочинённых заданий и не гарантия распознавания любой новой темы. Для незнакомых запросов включён порог уверенности; если он не достигнут, помощник просит выбрать предмет.

В приложении модель загружается с хостинга Lectrus только при открытии ИИ-помощника, затем сохраняется в браузере для следующих запусков. Новая версия модели автоматически получает новый ключ кэша. Классификация выполняется в браузере. Внешний API, сервер модели и запросы к Supabase для распознавания не используются. Сохранение материалов и работа доски продолжают использовать обычное хранилище приложения.
