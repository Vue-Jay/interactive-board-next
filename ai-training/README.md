# Локальный классификатор предметов

Модель распознаёт школьный предмет по теме запроса. Она не сочиняет текст сама: после распознавания задания формирует существующий локальный генератор Lectrus.

## Обучение

Нужен Python 3.12+; дополнительных библиотек и доступа к интернету не требуется.

```powershell
npm run train:ai-subject-model
npm run build
```

Скрипт берёт темы из `subject_topics.json`, расширяет их двенадцатью вариантами формулировок и обучает мультиномиальный классификатор с символьными и словесными признаками. Проверка отдельно измеряет новые формулировки знакомых тем и темы, целиком исключённые из обучения. Обучающая и проверочная выборки детерминированы.

Текущий корпус содержит 742 учебные темы по 11 предметам: математика — 109, обществознание — 72, история — 81, остальные восемь предметов — по 60. Последний прогон обучался на 10 656 примерах. Порог уверенности калибруется отдельно на 150 формулировках знакомых тем и 1 520 запросах с темами, исключёнными из обучения; финальные проверочные наборы содержат соответственно 1 034 и 1 480 примеров. Размер модели — 1 447 475 байт (1,45 МБ; 1,38 МиБ), словарь — 5 800 признаков. На финальных наборах классификатор показал 97,2% точности на новых формулировках знакомых тем и 69,5% на новых темах. Порог 8,209 подобран для не менее 99% точности калибровочной выборки; на финальных выборках уверенно принимается 43,5% запросов знакомых тем и 13,3% новых тем, точность принятых ответов — 100% в обеих выборках. Остальные запросы должны уточняться. Точные темы из корпуса сверяются по компактному индексу: 742/742 распознаны правильно. Это проверка на собственном ограниченном корпусе, а не доказательство понимания любого пользовательского запроса.

Для каждой из 742 тем сформирован базовый предметный выход; наборные и числовые проверки запускаются отдельно по темам, где есть проверяемые генераторы. Темы математики 1–4 классов сопоставлены с 14/14, 19/19, 23/23 и 21/21 кодами федеральной программы; проверены 150 заданий для 1 класса, 315 для 2, 195 генераций по 13 темам 3 класса и 165 генераций по 11 темам 4 класса. Добавлены 15 нестандартных математических задач с проверкой правильности ответов. 150 заданий математики 1 класса прошли арифметические и возрастные проверки. Во время 742 пробных генераций при заблокированной сети после загрузки модели сетевых обращений не было; проверка холодного запуска приложения без сети ещё не выполнена. Добавлены конкретные проверяемые расчётные задания по механике, теплоте, электричеству, химическим растворам и количеству вещества, генетике и ориентированию. Для 12 тем, посвящённых 11 произведениям, генератор проверяет автора и жанр по федеральным программам литературы для 5–9 и 10–11 классов; эти 12 ключей проверяются в приёмочном прогоне. При узкой теме используются безопасные форматы практики с критериями проверки. Параметры запроса сверяются на примерах количества, класса, сложности и типа работы; слово «олимпиадные» распознаётся как запрос на нестандартную задачу без отдельного режима в интерфейсе. Это не означает, что модель сочиняет произвольные ответы: задания формируют проверяемые шаблоны и генераторы приложения.

План дальнейшей работы и конечные критерии выпуска помощника находятся в [`ROADMAP.md`](./ROADMAP.md). Корпус тем — карта покрытия, не полный перечень всех федеральных результатов обучения; до достижения выпускных критериев помощник не должен заявляться как покрывающий всю школьную программу.

Чтобы повторить структурную проверку распознавания тем, параметров запроса и комплектов заданий, запустите `npm run eval:ai-curriculum`. Она выявляет пропуски структуры и повторения, но не заменяет содержательную оценку учителем.

В приложении модель загружается с хостинга Lectrus только при открытии ИИ-помощника, затем сохраняется в браузере для следующих запусков. Новая версия модели автоматически получает новый ключ кэша. Классификация выполняется в браузере. Внешний API, сервер модели и запросы к Supabase для распознавания не используются. Сохранение материалов и работа доски продолжают использовать обычное хранилище приложения.
